# Current Legacy and named recording source

This is the current cumulative development source, not a validated study release or a hardware-tested public player. Recording defaults to off. No player, recording file, private log or vendor binary is included in this overlay.

## Recording scope and safeguards

Ordinary previews are non-recording and retain task records only in memory. The controlled named configuration can offer explicit named recording; it does not enable Legacy recording. Legacy recording additionally requires STROOP_LEGACY_RAW_RECORDING_DEVELOPMENT and the unchanged strict controlled Windows XR Development policy. Editor, test and synthetic builds remain unavailable. There is no runtime gate override.

The portable build helper requires explicit controlled and Legacy options, matching isolated build intent and per-build defines. It clears ambient recording variables and rejects persisted recording defines. An ordinary or named-only build cannot silently become Legacy-enabled. The runtime preserves separate owner acknowledgement, two current headset choices, explicit SDK start, explicit recording/output start, source binding, bounds, revocation and file-identity checks.

Legacy design retains BCAD, lists 0/1/2/3 and B initially facing the participant. Plain preview confirmation remains non-recording. The current guide asks only for an explicitly chosen 1-2-practice-trial withdrawal check. It does not ask for another completed four-block run. Withdrawal can leave retained bytes and incomplete/UNKNOWN output; it does not erase files or justify a completed CSV receipt. No data upload is needed.

## Public preparation and reproducibility limits

The public overlay preserves the strict policies and current source behavior but disables both native fixture allowlists and both named/Legacy integration roots. Each empty root rejects before path resolution or filesystem access. No replacement or user-configurable fixture location is provided. Native harnesses, machine-only scripts, private results, raw logs, build directories and binaries are excluded.

The current public validation is limited to a separate managed compilation and metadata/IL inspection. The exact production source hashes, compiler configuration and exclusions are recorded in legacy-recording-public-manifest-20261109b.json. This does not build or execute a public Unity player or reproduce the private shipped binary. No Unity Editor, SDK, native storage fixture, player, current user application or recording was started or touched during public preparation.

The portable build/test source is retained without executing its Unity or native paths. The test compiler locator now requires the Windows environment rather than a fixed local fallback. Prior sanitized evidence notes/manifests are historical provenance only; this cumulative overlay is intended for one current source tree, not a stack of historical publication branches.

The existing installed HTC dependency is not bundled or redistributed. No new project license grant is added. A separately reviewed package, explicit local choice and independent verification would still be required before claiming actual file capture or completed raw/CSV output.
